# Как работает бюджет {#how-budgeting-works}

Бюджет помогает понять, сколько денег у вас есть и можете ли вы позволить себе покупку. Actual использует [метод конвертов](../getting-started/envelope-budgeting.md): вы распределяете по категориям только те деньги, которые уже получили. Прогнозируемый доход в доступную сумму не включается.

Категории работают как отдельные «конверты». Вы видите, сколько выделили на каждую цель и сколько осталось после расходов. Остатки могут переходить на следующий месяц.

## Создание бюджета {#creating-a-budget}

Если вы составляете бюджет впервые:

1. Добавьте счета. Их текущие остатки определят сумму, которую можно распределить.
2. В столбце **Запланировано** укажите, сколько хотите потратить по каждой категории в этом месяце. Суммы можно изменить позже.
3. Распределяйте деньги, пока показатель **К распределению** не станет равным нулю.
4. При необходимости [настройте категории](./categories.md).

## Повседневная работа с бюджетом {#the-budgeting-workflow}

Бюджет меняется вместе с жизнью. Если в одной категории денег не хватило, перенесите часть из другой. В начале следующего месяца скорректируйте план с учётом прошлых расходов.

Полезный порядок действий:

1. Регулярно добавляйте или импортируйте операции и назначайте им категории.
2. Проверяйте перерасход. При необходимости перенесите деньги из другой категории или покройте перерасход в следующем месяце.
3. Полученный доход распределяйте сейчас либо откладывайте для бюджета следующего месяца.
4. В конце месяца составьте план на следующий месяц из доступных средств.
5. Оставшиеся деньги направьте в категорию сбережений или на конкретную цель.

## Как переносятся остатки {#how-money-rolls-over}

### Доход {#income}

Новый доход сразу попадает в доступные средства. Если не распределить его в текущем месяце, он перейдёт в следующий. Наведите указатель на сумму доступных средств, чтобы увидеть доходы по месяцам.

Чтобы зарезервировать деньги для следующего месяца:

1. Нажмите на сумму **К распределению**.
2. Выберите **Отложить на следующий месяц**.
3. Нажмите <Key k="enter" />, чтобы отложить всю сумму, или введите нужную часть.

![Отложить средства на следующий месяц](/img/how-it-works/buffer-1.webp)

Деньги исчезнут из суммы **К распределению** за текущий месяц и появятся в следующем. Это помогает жить на доход прошлого месяца. При необходимости отложенные деньги можно вернуть в текущий месяц через команду сброса резерва следующего месяца. Если средства откладывались на несколько месяцев вперёд, сбрасывайте резерв последовательно для каждого месяца.

:::note
Если в новом месяце показатель **К распределению** неожиданно отрицательный, проверьте резерв следующего месяца: часть денег могла остаться отложенной.
:::

Отдельные категории доходов можно [автоматически откладывать](#automatic-holding-of-funds) на будущие месяцы.

### Перерасход {#overspending}

Если расходы по категории превысили выделенную сумму, перерасход нужно покрыть. Обычно деньги переносят из другой категории. Непокрытый перерасход Actual автоматически вычитает из суммы **К распределению** следующего месяца, а остаток категории сбрасывает до нуля.

Положительный остаток категории, напротив, переходит в ту же категорию следующего месяца.

## Работа с бюджетом {#working-with-the-budget}

### Перенос денег между категориями {#moving-money-around}

Деньги можно переносить между категориями и суммой **К распределению**:

1. Нажмите на остаток нужной категории.
2. Выберите перенос в другую категорию.
3. Введите сумму и выберите категорию назначения или **К распределению**.
4. Подтвердите перенос.

Перенос можно начать и с суммы **К распределению**.

### Бюджет на следующий месяц {#creating-new-budgets-for-the-next-month}

План на новый месяц составляется заново из доступных денег. Можно указать суммы вручную или открыть меню **⋮** в правом верхнем углу месяца и скопировать бюджет прошлого месяца. Там же есть другие варианты автоматического заполнения.

### Перенос отрицательного остатка {#rollover-negative-category-balances}

Иногда отрицательный остаток категории нужно сохранить, например при расходах, которые вам позже возместят:

1. Нажмите на остаток категории.
2. Выберите **Перенести перерасход**.

После этого отрицательный остаток будет переходить в следующие месяцы.

### Автоматическое резервирование дохода {#automatic-holding-of-funds}

Если вы регулярно планируете следующий месяц на текущий доход, включите автоматическое резервирование для нужной категории доходов. Для этого нажмите на сумму дохода категории и выберите соответствующую команду.

![Меню автоматического резервирования](/img/how-it-works/auto-hold.webp)

После включения рядом с категорией появится стрелка. Резервирование действует с текущего месяца и на следующие 12 месяцев. Чтобы отключить его, снова нажмите на сумму дохода и выберите отключение.

![Индикатор автоматического резервирования](/img/how-it-works/auto-hold-carryover.webp)

Если нужно изменить резерв только в текущем месяце, нажмите на запланированную сумму и отключите автоматическое резервирование для этого месяца. В будущих месяцах настройка сохранится.

![Отключение резервирования на текущий месяц](/img/how-it-works/auto-hold-disable.webp)

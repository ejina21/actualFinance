# Проблемы с конфигурацией сервера {#troubleshooting-server-configuration-issues}

Использует стандартный Node.js `debug` модуль для опционального входа полезной отладки информации на консоль.

Если ваши параметры конфигурации (установленные либо в файле конфигурации, либо в качестве переменных среды) не применяются, вы можете включить отладку регистрации, добавив переменную среды, названную `DEBUG` с ценностью `actual:config`Если вы видите проблемы с конфигурацией HTTPS, вы можете вместо этого установить значение для `actual:config,actual-sensitive:config` регистрировать фактические значения секретов HTTPS (которые по умолчанию скрыты, чтобы они не просочились непреднамеренно).

Может быть полезно сравнить ваш файл конфигурации со схемой конфигурации. [/packages/sync-server/src/load-config.js](https://github.com/actualbudget/actual/blob/45530638feaacf74c28fddb846ae91170a99d94e/packages/sync-server/src/load-config.js#L43)

## Диагностика Входа И Банковских Подключений {#troubleshooting-sign-in-and-bank-connections}

Обычные журналы содержат пути запросов, статусы ответов и краткие описания ошибок. Подробные ошибки провайдеров доступны через диагностические журналы с конфиденциальными данными.

:::caution
Такие журналы могут содержать учётные данные, банковскую информацию и другие личные сведения. Они выводятся в существующую консоль сервера или журналы контейнера, без отдельного файла. Не публикуйте их в общедоступных обсуждениях. Если сопровождающий просит журнал, договоритесь о частной передаче, например в личных сообщениях Discord.
:::

1. Добавьте нужное значение в переменную окружения `DEBUG` сервера. Если она уже задана, дополните её через запятую.

   | Проблема                        | Значение `DEBUG`                                             |
   | ------------------------------- | ------------------------------------------------------------ |
   | Вход OpenID                     | `actual-sensitive:openid`                                    |
   | Подключение Enable Banking      | `actual-sensitive:enable-banking,actual-sensitive:bank-sync` |
   | Подключение Akahu               | `actual-sensitive:bank-sync`                                 |
   | Подключение SimpleFIN           | `actual-sensitive:simplefin,actual-sensitive:bank-sync`      |
   | Подключение GoCardless          | `actual-sensitive:gocardless,actual-sensitive:bank-sync`     |
   | Подключение Pluggy              | `actual-sensitive:pluggy,actual-sensitive:bank-sync`         |
   | Другие ошибки сервера           | `actual-sensitive:server`                                    |
   | Скачивание плагина через прокси | `actual-sensitive:cors-proxy`                                |

2. Перезапустите сервер и повторите действие, завершившееся ошибкой.
3. Сохраните соответствующий вывод для сопровождающего.
4. Верните прежнее значение `DEBUG` и перезапустите сервер. Отключение журналирования не удаляет уже собранные данные.

Включайте только необходимое пространство имён. `DEBUG=actual:*` включает обычную диагностику без конфиденциальных пространств. Широкие шаблоны `DEBUG=*` и `DEBUG=actual*` включают и конфиденциальный вывод, в том числе существующее журналирование секретов конфигурации.

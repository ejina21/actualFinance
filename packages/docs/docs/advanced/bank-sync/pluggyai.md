# Настройка Pluggy.ai {#pluggyai-setup}

### Создание идентификатора клиента и секрета клиента для фактического {#create-client-id-and-client-secret-for-actual}

1. Создать аккаунт в [https://pluggy.ai](https://pluggy.ai).
2. Подпишитесь на [Pluggy Dashboard](https://dashboard.pluggy.ai/) И создать новую команду.

   ![](/img/connecting-your-bank/pluggy-console-01.webp)

3. В Pluggy Dashboard создайте **Применение** Перед созданием API-ключей:
   - щелкнуть **Приложения** в верхней строке и создать новое приложение.
   - Создав его, вы увидите **Клиентский ID** и **Секрет клиента**.

   ![](/img/connecting-your-bank/pluggy-console-02.webp)

4. Храните обе ценности надежно, они вам понадобятся в действии.

---

### Скачать Meu Pluggy {#setup-meu-pluggy}

Meu Pluggy - это бесплатная интеграция, предоставляемая Pluggy.ai для разработчиков. Вам необходимо синхронизировать свой банк, используя этот инструмент для доступа к нему бесплатно.

1. Визит [Meu Pluggy](https://meu.pluggy.ai) Входите или регистрируйтесь.
2. Следуйте инструкциям, предоставленным на официальном [хранилище github](https://github.com/pluggyai/meu-pluggy).

:::info
Обратите внимание, что вы сможете подключить свою учетную запись только к meu.pluggy.ai, пока ваш пробный период pluggy.ai активен, поэтому, пожалуйста, быстро завершите этот шаг. После истечения пробного периода учетная запись останется подключенной, но конфигурация списка разъемов не будет редактироваться.

![](/img/connecting-your-bank/pluggy-trial-warning.webp)
:::

3. После выполнения шагов в item 2 , вернитесь на панель управления Pluggy. Перейдите в созданное вами приложение и нажмите «Ir para Demo», чтобы открыть демо-приложение.
4. В правом верхнем углу откройте меню из трех точек. Откройте его и нажмите **Копиарный элемент ID** От синхронизации вашего банка до буфера обмена. Вам понадобится это, чтобы завершить настройку синхронизации банка Pluggy.ai.

![](/img/connecting-your-bank/pluggy-console-03.webp)

### Настройка Pluggy в реальном времени {#set-up-pluggy-in-actual}

Интеграция плагинов является экспериментальной на данный момент, поэтому, прежде чем вы сможете использовать ее, вам нужно включить ее в разделе Настройки -> Расширенные настройки -> Экспериментальные функции -> Синхронизация Pluggy.ai Bank

1. На самом деле, кликните **+ Добавить аккаунт** В нижней части боковой панели.

   ![](/img/advanced/bank-sync/bank-sync-add-account@2x.webp)

2. Выберите **Настроить банковскую синхронизацию** и затем **Настроить** на карточке Pluggy.ai в разделе **Провайдеры**.

   ![](/img/advanced/bank-sync/bank-sync-add-account-modal@2x.webp)

3. В диалог, который появляется, введите:
   - **Клиентский ID**Из вашей Pluggy Dashboard
   - **Секрет клиента**Из вашей Pluggy Dashboard
   - **Идентификаторы пунктов**Разделенная запятая при входе более чем в одну

   ![](/img/advanced/bank-sync/pluggyai-setup-modal@2x.webp)

4. щелкнуть **Спасти**Учетные данные будут надежно храниться на сервере.

### Ссылки на аккаунты с Pluggy {#link-accounts-with-pluggy}

1. Связать банковский счет (существующий или новый):
   - Для одного **существующий счет**Нажмите на него, затем нажмите `...` (кебаб-меню) и выбрать **Ссылка на аккаунт**.

     ![](/img/advanced/bank-sync/bank-sync-link-account-menu@2x.webp)

   - Для **Новый аккаунт**щелкните **+ Добавить аккаунт** На боковой панели.

     ![](/img/advanced/bank-sync/bank-sync-add-account@2x.webp)

2. Выбрать **Связать свой банковский счет** с Pluggy.ai.

   ![](/img/advanced/bank-sync/pluggyai-link-bank-account@2x.webp)

3. Появится список учетных записей из вашего подключения Pluggy.
4. щелкнуть **Создать банк-синхрон** рядом с тем, который вы хотите синхронизировать.

   ![](/img/advanced/bank-sync/pluggyai-link-accounts@2x.webp)

### Pluggy Notes и ограничения {#pluggy-notes-limitations}

1. Идентификаторы элементов связаны с авторизованными пользователями соединениями и истекают, если доступ отозван или токен истекает.
2. Используйте среду песочницы для тестирования — тестовые учетные данные доступны в Интернете. [Pluggy Docs](https://docs.pluggy.ai/docs/quick-pluggy-introduction#sandbox-environment).
3. Частота обновления данных может варьироваться в зависимости от финансового учреждения.

### Перезагрузка Pluggy Credentials {#resetting-pluggy-credentials}

Чтобы восстановить соединение Pluggy:

1. На самом деле, кликните **Добавить аккаунт**.
2. Рядом с «Set-up Pluggy for bank-sync» откройте меню из трех точек.
3. щелкнуть **Сброс учетных данных Pluggy**.

Затем вам нужно будет создать новый ключ API и получить новый идентификатор элемента для повторного подключения.

## Настройка Провайдера В Настройках {#provider-settings}

В диалоге добавления счёта выберите **Настроить банковскую синхронизацию**. Откроется страница **Банковская синхронизация** в настройках. В разделе **Провайдеры** нажмите **Настроить** на карточке Pluggy.ai, введите учётные данные и нажмите **Сохранить и продолжить**.

Чтобы связать счёт, нажмите **Подключить банковский счёт** на карточке Pluggy.ai. Возле нужного банковского счёта выберите **Настроить банковскую синхронизацию**, укажите счёт Actual и нажмите **Связать счета**. Для существующего счёта также доступна команда **Связать счёт** в меню **…** страницы счёта.

![Настройка Pluggy.ai в разделе провайдеров](/img/advanced/bank-sync/pluggyai-set-up@2x.webp)

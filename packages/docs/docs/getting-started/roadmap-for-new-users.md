# С чего начать {#roadmap-for-new-users}

Если вы впервые открыли Actual, выберите подходящий путь:

## Хочу сначала посмотреть приложение

Начните с [обзора Actual](../tour/index.md). Он знакомит с бюджетом, счетами, операциями, правилами и отчётами.

## Хочу научиться вести бюджет

Прочитайте [основы метода конвертов](./envelope-budgeting.md), затем [создайте первый бюджет](./starting-fresh.md). Дальше пригодится раздел [«Как работает бюджет»](../budgeting/index.md).

## Хочу пользоваться Actual на одном компьютере

Откройте [страницу загрузки](../../download) и установите приложение для своей операционной системы. Для работы на одном устройстве сервер не требуется.

## Хочу синхронизировать несколько устройств

Прочитайте [руководство по установке](../install/index.md), чтобы выбрать способ запуска сервера. Там есть инструкции для собственного компьютера и облачного размещения.

## Уже есть данные в другой программе

Посмотрите [инструкции по переносу](../migration/index.md). Они помогут импортировать бюджет из поддерживаемого приложения.

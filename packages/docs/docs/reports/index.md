# Отчёты и панель обзора {#reports-dashboard}

В Actual можно анализировать доходы, расходы и состояние счетов с помощью отчётов. Начальная панель обзора показывает доступные возможности. Вы можете менять её состав, добавлять виджеты и создавать дополнительные панели для разных задач.

Для отчётов доступны фильтры и диапазоны дат: фиксированные или автоматически обновляемые.

![Панель отчётов](/img/reports/dashboard.webp)

Встроенные отчёты и виджеты:

- [Денежный поток](#cash-flow-graph)
- [Чистый капитал](#net-worth-graph)
- [Анализ расходов](#spending-analysis)
- [Сводная карточка](#summary-card)
- [Календарь](#calendar-card)
- [Текстовый виджет](#text-widget)
- [Настраиваемые отчёты](./custom-reports.md)
- [Точка финансовой независимости](#crossover-point)

Отдельно доступны [экспериментальные отчёты](../experimental/index.md): анализ бюджета, прогноз остатка, диаграмма Санки и моделирование Монте-Карло.

## Денежный поток {#cash-flow-graph}

![График денежного потока](/img/reports/cash-flow.webp)

График показывает, как со временем меняется сумма на счетах, входящих в бюджет. Доходы и расходы отображаются отдельно, поэтому видно, как они влияют на доступные деньги.

## Чистый капитал {#net-worth-graph}

![График чистого капитала](/img/reports/net-worth.webp)

Чистый капитал — это стоимость денег и активов за вычетом долгов. График учитывает все счета, включая внебюджетные. Он помогает увидеть, как меняется ваше финансовое положение со временем.

Режим **Тренд** показывает общую сумму. Режим **По счетам** показывает вклад каждого счёта, например сбережений и инвестиций. Если одновременно есть положительные и отрицательные остатки, второй режим может быть сложнее для чтения.

![Чистый капитал по счетам](/img/reports/net-worth-stacked.webp)

## Анализ расходов {#spending-analysis}

![Анализ расходов](/img/reports/spending-analysis.webp)

Отчёт сравнивает расходы за выбранный период и помогает заметить тенденции, перерасход и возможности для экономии.

## Текстовый виджет {#text-widget}

![Текстовый виджет](/img/reports/text-widget.webp)

Добавьте текст в формате Markdown, чтобы подписывать группы отчётов или оставлять пояснения на панели.

## Сводная карточка {#summary-card}

![Сводная карточка](/img/reports/summary-card.webp)

Карточка показывает итог по операциям за выбранный период. Среди вариантов — общая сумма и среднемесячное значение.

## Календарь {#calendar-card}

![Календарь доходов и расходов](/img/reports/calendar-card.webp)

Календарь показывает доходы и расходы по дням за выбранный период.

## Точка финансовой независимости {#crossover-point}

![График точки финансовой независимости](/img/reports/crossover-point-report/full-chart.webp)

Отчёт прогнозирует, когда пассивного дохода от инвестиций может хватить для покрытия будущих расходов. Эта точка на графике означает достижение финансовой независимости в рамках выбранных допущений.

### Параметры отчёта {#input-parameters}

| Параметр                     | Для чего нужен                                                                                                                                       |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Категории расходов**       | Выберите расходы, которые сохранятся в будущем. Разовые или исчезающие расходы, например некоторые рабочие траты, можно исключить.                   |
| **Счета для расчёта дохода** | Выберите инвестиционные и пенсионные счета, которые будут обеспечивать пассивный доход.                                                              |
| **Безопасная норма снятия**  | Годовая доля портфеля, которую вы планируете тратить. Исходное значение — 4%; измените его с учётом своих допущений и риска.                         |
| **Метод прогноза расходов**  | Выберите среднее, медиану или медиану с фильтром Хампеля, который уменьшает влияние необычно больших или малых расходов.                             |
| **Ожидаемая доходность**     | Укажите предполагаемую годовую доходность. Если оставить поле пустым, Actual оценит её по истории счетов; взносы в счёт могут завышать такую оценку. |

### Как строится прогноз {#how-it-works}

Actual прогнозирует будущие расходы по выбранным категориям и методу расчёта. Затем оценивает пассивный доход на основе выбранных счетов, доходности и нормы снятия. Точка пересечения линий показывает момент, когда прогнозируемый доход превышает расходы.

## Какой способ ведения бюджета выбрать?

В Actual есть два способа ведения бюджета: [бюджетирование по конвертам](../getting-started/envelope-budgeting.md) и более привычное [отслеживание бюджета](../getting-started/tracking-budget.md). При бюджетировании по конвертам вы распределяете только те деньги, которые уже есть у вас, а не ожидаемые будущие доходы. Отслеживание бюджета позволяет планировать будущие поступления. По умолчанию Actual использует конверты; мы рекомендуем начать с них.

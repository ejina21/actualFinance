# Предварительные сборки {#preview-builds}

Каждый запрос на вытягивание автоматически развертывает сборки предварительного просмотра в Netlify, поэтому вы можете попробовать изменения без клонирования ветви.

Чтобы найти PR, просмотрите [Запросы Open pull](https://github.com/actualbudget/actual/pulls)Если у вас есть PR-номер, замените его. `{pr-number}` В URL ниже.

Три предварительных просмотра развернуты на PR:

- **Демо:** `https://deploy-preview-{pr-number}.demo.actualbudget.org/`
- **Рассказчик:** `https://deploy-preview-{pr-number}--actualbudget-storybook.netlify.app/`
- **Сайт:** `https://deploy-preview-{pr-number}.www.actualbudget.org/`

Точные URL-адреса также публикуются в качестве комментария к каждому PR ботом Netlify.

Демо-превью служит для подачи уведомлений в приложении из собственной сборки (`packages/desktop-client/src/data/news.json` как совершено в PR-отделении), поэтому сообщение в блоге, добавленное в PR, отображается в предварительном просмотре приложения после того, как CI регенерировал ленту. `REACT_APP_NEWS_FEED_URL` в `.env` файл в `packages/desktop-client` Чтобы указать приложение на любой другой URL-адрес.

:::info
В сборках предварительного просмотра нет синхронизирующего сервера, поэтому, когда вас спрашивают «Где сервер», выберите «Не используйте сервер». Вы должны проявлять осторожность при использовании сервера с сборками предварительного просмотра, потому что у них гораздо больше шансов иметь ошибки, которые могут повредить ваш бюджет. Рассмотрите возможность запуска отдельного локального сервера для сборок предварительного просмотра.
:::

## Ночные постройки {#nightly-builds}

Ночные сборки служат испытательным полигоном для предстоящих функций, прежде чем они будут включены в официальные ежемесячные выпуски.
Исследуйте ночные сборки, чтобы получить доступ к последним функциям, но имейте в виду, что новые функции добавляются и удаляются регулярно, что означает, что эти сборки не всегда стабильны.

### Ночные веб-строительства {#nightly-web-builds}

Если вы хотите попробовать ночную сборку веб-приложения, просто перейдите к [Nightly.actualbudget.org](https://nightly.actualbudget.org/).

:::info
На ночной сборке нет синхронизирующего сервера, поэтому на вопрос «Где сервер?» выберите «Не используйте сервер». Вы должны проявлять осторожность при использовании сервера с ночными сборками, потому что у них гораздо больше шансов иметь ошибки, которые могут повредить ваш бюджет. Рассмотрите возможность запуска отдельного локального сервера для ночных сборок.
:::

### Ночной рабочий стол строит {#nightly-desktop-builds}

The [настольное приложение](../install/desktop-app.md) Он также строится каждую ночь. Постройки публикуются в виде загружаемых артефактов. [Опубликовать ночное настольное приложение](https://github.com/actualbudget/actual/actions/workflows/publish-nightly-electron.yml) Рабочий процесс GitHub.

Чтобы загрузить последнюю ночную сборку рабочего стола:

1. Подписаться [GitHub](https://github.com/login)Вам нужна учетная запись GitHub (бесплатная - это нормально), так как GitHub позволяет только зарегистрированным пользователям загружать артефакты рабочего процесса.
2. Открой. [Список ночных настольных сборок](https://github.com/actualbudget/actual/actions/workflows/publish-nightly-electron.yml?query=is%3Asuccess) и нажмите последний запуск в верхней части списка.
3. Прокрутите вниз к **Артефакты** Раздел внизу страницы.
4. Загрузите артефакт, который соответствует вашей операционной системе и архитектуре процессора.
5. Артефакт загружается как `.zip` Извлеките его, чтобы получить установщик, а затем установите его, как обычное настольное приложение.

# Интернационализация {#internationalization}

Вы заинтересованы в привлечении фактической аудитории путем перевода и локализации приложения на новые языки? Отлично! Это руководство покажет вам, как начать. Добавление переводов может быть отличным первым шагом в содействии программному обеспечению с открытым исходным кодом.

## Перевод существующих строк {#translating-existing-strings}

Actual использует [Weblate](https://hosted.weblate.org/projects/actualbudget/actual) для управления переводами. Чтобы предложить перевод, создайте учётную запись Weblate и включите двухфакторную аутентификацию. Предложения проходят проверку перед включением в приложение.

В настоящее время мы включаем языки в приложение только после того, как было переведено не менее 50% строк.

:::note Запросы Pull

Мы не принимаем GitHub Pull Requests, изменяющие файлы перевода; любые PR в репозитории переводов будут автоматически закрыты.

:::

### Предлагаю новый перевод {#suggesting-a-new-translation}

Чтобы предложить перевод для языка, с которым вы знакомы, просто найдите строку, которую вы хотели бы перевести, заполните перевод и нажмите «Предлагаю». Это затем даст другим возможность проголосовать за самый точный перевод. [Документы Weblate](https://docs.weblate.org/en/latest/user/translating.html) для более подробной информации.

Пожалуйста, заполните только те переводы, в которых вы уверены, и обязательно включите те же маркеры форматирования, что и в тексте на английском языке. `<1>English</1>` -> `<1>Anglais</1>`).

### Голосование по существующим предложениям {#voting-on-existing-suggestions}

Чтобы поддерживать высокую планку качества перевода, предлагаемые переводы не принимаются, пока они не получат по крайней мере два голоса.

Вы можете помочь определить высококачественные переводы, проголосовав за них! Нажмите на «Строки с предложениями» с языковой страницы и используйте значки «большие пальцы вверх или большие пальцы вниз» для голосования. Если вы нажимаете «большие пальцы вниз», всегда полезно указать причину, чтобы оригинальный переводчик мог улучшить.

Если вы видите неправильный перевод или вредоносный вклад, пожалуйста, пометьте его в `#project-translate` канал на Discord, чтобы администратор мог его просмотреть.

## Маркировка новых строк для перевода {#marking-new-strings-for-translation}

Разработка программного обеспечения для перевода требует, чтобы каждый текст, показанный пользователю, проходил через функцию перевода. [i18next](https://www.i18next.com/) для достижения этой цели.

Струны в Actual переводятся их естественной версией на английском языке.Проект не использует искусственные клавиши для выбора соответствующего переведенного текста из каталога сообщений.

:::note Использование клавиш естественного языка

Рассмотрим текст `"Welcome to Actual Budget"`При маркировке строк для перевода с использованием естественного языка эта строка также становится ключом, используемым для перевода на другие языки. Это в отличие от обычно используемой альтернативы использования искусственных ключей, которая будет выглядеть как `"text_welcome"`Actual Budget **не** Используйте эти ключи.

:::

При подготовке ваших переводимых строк, пожалуйста, используйте полные блоки для перевода. Если есть сплочённый абзац с несколькими предложениями, пометьте весь абзац как одну переводимую строку. Не разделяйте его на несколько текстов.

Структура перевода предусматривает два основных метода перевода:

### `t()` Функция {#t-function}

The `t()` Функция является простейшей формой перевода, она принимает перевод текста и необязательный объект с интерполяционными переменными. `i18next` Вы можете использовать крючок в компонентах React, чтобы получить ссылку на него.

```javascript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();

  return <button aria-label={t('Hello World')} />;
}
```

Во время выполнения он выберет перевод из текущего активного местоположения. Вы также можете добавить переменные в [интерполировать](https://www.i18next.com/translation-function/interpolation):

```javascript
const withPlaceholder = t('Welcome home, {{name}}!', { name: 'Anita' });
```

Для [плюрализм](https://www.i18next.com/translation-function/plurals)Пожалуйста, используйте форму множественного числа для текста по умолчанию. **должен** называться `count`:

```javascript
const manyItems = t('You selected {{count}} items', { count: 4 });
```

i18next позаботится о правилах плюрализации на активном языке и предоставит несколько различных форм, если это необходимо.

### `<Trans>` компонент {#component}

При переводе текста с помощью простых тегов HTML или других компонентов React мы просим вас использовать [`<Trans>` компонент](https://react.i18next.com/latest/trans-component).

```javascript
import { Trans } from 'react-i18next';

function MyComponent() {
  return (
    <Trans>
      Click <Link href={url}>here</Link> to become a millionaire.
    </Trans>
  );
}
```

#### Интерполирование с `<Trans>` {#interpolation-with}

Обработка переменных заполнителей и плюрализация внутри `<Trans>` Компонент React обрабатывается немного по-другому. Для более подробной информации, пожалуйста, обратитесь к [Документация i18next-react](https://react.i18next.com/latest/trans-component#interpolation).

```javascript
import { Trans } from 'react-i18next';

function MyComponent() {
  const person = { name: 'Pedro' };
  // You can use an object literal within <Trans>!
  return <Trans>Your name is {{ name: person.name }}.</Trans>;
  // This will result in the translation string:
  // "Your name is {{name}}."
}
```

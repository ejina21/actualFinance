# Миграции базы данных {#db-migrations-guide}

Есть несколько важных соображений, которые следует учитывать при добавлении функции с миграцией db.

- Для DB Migrations потребуется публикация новой версии API, поскольку в ней также необходимо будет применять миграции.

- Файл AQL Schema, вероятно, потребуется обновить, чтобы соответствовать любым изменениям таблицы.

- Вы должны разместить свой миграционный файл в `loot-core/migrations` папка, со строгим соглашением об именах.

- Конвенция об именовании заключается в следующем: `TIMESTAMP_name.sql`Например. `1694438752000_add_goal_targets.sql`

- Крайне не рекомендуется пытаться удалять столбцы и таблицы. Это делает невозможным возврат изменений и вводит ненужный риск, когда мы можем просто перестать использовать их в коде.

- При добавлении функции постарайтесь подумать о будущих сценариях и вариантах, которые могут быть желательны позже, чтобы мы могли минимизировать количество миграций.

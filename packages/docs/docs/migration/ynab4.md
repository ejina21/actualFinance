# Перенос из YNAB 4 {#migrating-from-ynab4}

- Иди к нему. **Создайте новый файл** Экран (это первый экран, который вы видите при первом запуске).
- щелкнуть **Импорт...**
- Все существующие бюджеты YNAB4 должны быть перечислены. Выберите тот, который вы хотите импортировать.
- щелкнуть **импорт**
- Вот так!

## Известные проблемы {#known-issues}

- Сплит-транзакции могут импортироваться неправильно. В YNAB4 сплит-транзакция отслеживает получателя на родительском уровне, в то время как в Actual получатель, показанный на родительском уровне, присоединяется к получателю сплит. Поскольку у разделений нет правильных получателей, они могут не отображаться в отчетах и фильтрах. Решение заключается в использовании настроек / Показать расширенные настройки / Ремонт раздельных транзакций. Это нужно будет сделать только один раз.

# Сверка счёта {#reconciliation}

Сверка помогает убедиться, что список операций и остаток в Actual совпадают с выпиской банка. Её можно проводить раз в месяц, раз в неделю или чаще. В Actual для этого есть отдельный инструмент.

## Как устроена сверка {#work-flow}

Сравните операции в Actual с банковской выпиской. Неподтверждённые операции отмечены серым кружком. Когда найдёте операцию в выписке, нажмите на кружок: он станет зелёным, а операция получит статус подтверждённой.

Нажмите на зелёный остаток в заголовке счёта, чтобы увидеть две дополнительные суммы: **подтверждённый остаток** по операциям, сверенным с банком, и **неподтверждённый остаток** по остальным операциям.

![Остатки в заголовке счёта](/img/reconcile/reconcile-1.webp)

## Как запустить инструмент сверки {#starting-the-reconciliation-tool}

Нажмите значок замка 🔒 в правом верхнем углу списка операций. При наведении на него показывается дата последней сверки.

![Значок замка](/img/reconcile/reconcile-2-2025.webp)

Введите остаток из банковской выписки и нажмите **Сверить**. Изначально инструмент сравнивает его с подтверждённым остатком в Actual.

:::tip
Для кредитной карты или займа указывайте отрицательный остаток.
:::

![Окно сверки без синхронизации с банком](/img/reconcile/reconcile-3-2025.webp)

Если ваш банк передаёт остаток при синхронизации, можно выбрать **Использовать последний синхронизированный остаток**.

![Окно сверки с синхронизацией](/img/reconcile/reconcile-3a-2025.webp)

Инструмент покажет разницу между остатком банка и Actual. Сравнивайте операции с выпиской и отмечайте совпавшие серые кружки зелёным. Разница должна постепенно уменьшиться до нуля. Удобнее держать выписку и список операций рядом.

![Разница при сверке](/img/reconcile/reconcile-4-2025.webp)

Когда остатки совпадут, появится сообщение об успешной сверке. Нажмите **Заблокировать операции**, чтобы завершить её. Если хотите продолжить позже, выберите **Выйти из сверки**.

:::warning
До нажатия **Заблокировать операции** подтверждённые операции не получат статус заблокированных, даже если остатки уже совпали.
:::

![Успешная сверка](/img/reconcile/reconcile-5-2025.webp)

![Заблокированные операции](/img/reconcile/reconcile-6-2025.webp)

Чтобы разблокировать операцию, нажмите на её замок и подтвердите действие. Статус вернётся к «Подтверждена»; для повторной блокировки понадобится новая сверка.

![Разблокировка операции](/img/reconcile/reconcile-7.webp)

При попытке изменить заблокированную операцию Actual покажет предупреждение. После подтверждения изменение сохранится, а операция останется заблокированной.

![Предупреждение при изменении операции](/img/reconcile/reconcile-12.webp)

## Учёт стоимости активов вне бюджета {#using-the-reconciliation-tool-for-off-budget-asset-tracking}

Счета вне бюджета подходят для отслеживания стоимости недвижимости, автомобиля, пенсионных накоплений и других активов. Чтобы обновить оценку, откройте инструмент сверки и выберите **Создать операцию сверки**.

Например, стоимость дома выросла с 231 100 до 234 600. Откройте счёт этого актива и введите новую стоимость — 234 600.

![Новая стоимость актива](/img/reconcile/reconcile-8-2025.webp)

Инструмент покажет изменение на 3 500.

![Изменение стоимости](/img/reconcile/reconcile-9-2025.webp)

Нажмите **Создать операцию сверки**. Actual добавит операцию, которая приведёт остаток к новой оценке. Затем нажмите **Заблокировать операции**, чтобы завершить сверку.

![Созданная операция сверки](/img/reconcile/reconcile-10-2025.webp)

![Завершённая сверка актива](/img/reconcile/reconcile-11-2025.webp)

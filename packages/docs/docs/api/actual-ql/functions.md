# Функции ActualQL {#actualql-functions}

## Присоединяйтесь к столам {#joining-tables}

Возможно, вы заметили, что `category.name` Что именно это поле и почему мы не можем просто использовать `category`?

The `category` в поле `transactions` является `id`Вы можете дать ему определенный идентификатор категории для фильтрации; вы не хотите давать ему такое имя, как `Home` Поскольку несколько категорий могут существовать с одним и тем же названием в разных группах, предоставляя ему идентификатор категории, вы знаете, что получаете транзакции, специфичные для этой категории.

Тем не менее, у вас часто нет идентификатора категории и вы хотите быстро искать по названию категории. `.` оператор в названии поля «прозвонит» в указанную таблицу и позволит вам получить доступ к любым полям на ней. `categories` столик.

Таким образом, фильтрация `category.name` позволяет искать по имени, а не по идентификатору. `category`; например, `{ 'category.is_income': true }` Мы найдем все категории доходов.

## сортировка {#sorting}

Вы можете сортировать результаты с помощью `orderBy` функция:

```js
q('transactions')
  .filter({ 'category.is_income': true })
  .select('*')
  .orderBy('category.name');
```

Это возвращает транзакции с категорией дохода, отсортированной по названию категории. `orderBy` Сортировка по нескольким полям.

Вы также можете изменить порядок сортировки, указав либо `asc` или `desc`:

```js
q('transactions')
  .filter({ 'category.is_income': true })
  .select('*')
  .orderBy({ 'category.name': 'desc' });
```

## Агрегированные функции {#aggregate-functions}

Вы можете указать совокупные функции в `select` Для таких вещей, как суммы и подсчеты.

```js
q('transactions')
  .filter({ 'category.name': 'Food' })
  .select({ total: { $sum: '$amount' } });
```

Это суммирует сумму всех сделок с `Food` Категория (как правило, вы будете фильтровать по дате). **Совокупные результаты должны быть названы**Здесь мы его назвали `total`Вы получите ошибку, если не назовете ее. (в будущем мы можем удалить это ограничение)

Поскольку выбор одного совокупного выражения настолько распространен, ActualQL предоставляет другой метод их запуска: `calculate`Приведенный выше запрос может быть переписан следующим образом:

```js
q('transactions')
  .filter({ 'category.name': 'Food' })
  .calculate({ $sum: '$amount' });
```

Мы не только не назвали результат, `data` В результате также будет суммировано само значение. `select`, данные будут массивом с одним элементом. Разница в том, что в приведенном выше вы просто используете `data`Если вы использовали `select` Вы должны использовать `data[0].total`.

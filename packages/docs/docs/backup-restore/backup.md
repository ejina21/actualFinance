# Резервное копирование бюджета {#backing-up-your-actual-budget}

:::note

Если ваш бюджет очень старый, у вас могут возникнуть проблемы с восстановлением больших резервных копий. Если вы столкнулись с этой проблемой, нажмите «Синхронизация сброса» в разделе «Настройки» > «Показать расширенные настройки» для синхронизации сброса, затем снова сделайте экспорт. Это должно уменьшить размер файла.

:::

**Почему синхронизация уменьшает размер файла?** По умолчанию Actual хранит все мутации в бюджетном файле. Каждый раз, когда вы добавляете транзакцию, меняете получателя, добавляете заметки, создаете правила, удаляете расписание и т. д., в бюджетном файле создается новая запись. Это приводит к росту файла с течением времени. При сбросе синхронизации или экспорте / реимпорте все эти исторические изменения сжимаются в один файл, что значительно уменьшает размер.

Вы можете экспортировать свои данные из Actual в любое время.

1. Войдите в свой бюджет, нажмите «Дополнительно» > «Настройки»

   ![](/img/backup-restore/sidebar-settings@2x.webp)

2. Прокрутите вниз до раздела «Экспорт» и нажмите «Экспортные данные»

   ![](/img/backup-restore/settings-export.webp)

3. Сохраните файл где-нибудь на вашем компьютере - вот и все - вы закончили.

## Ручное создание резервной копии из приложения Desktop {#manually-creating-a-backup-from-the-desktop-app}

Это заставит создать резервную копию прямо сейчас. Сделайте это, если вы собираетесь сделать что-то, что вы, возможно, захотите вернуть позже (и не хотите использовать) [отменять](../getting-started/tips-tricks.md#undo-redo)).

- Выберите **File > Загрузить резервную копию...** пункт меню
- щелкнуть **Обновление Now**
